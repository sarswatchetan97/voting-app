voting app functionality

1. user sign in/ sign up
2. see list of candidates
3. vote only one candidate, after voting, user can't vote
4. route which shows list of candidates and their live vote counts, sorted by vote counts
5. user data must contain unique government id proof named: aadhar card no.
6. one admin who can only maintain the table of candidates and will not be able to vote
7. user can change their password
8. user can login with aadhar card no and password

----------------------------------

ROUTES/ ENDPOINTS

User Authentication:
    /signup: POST - Create a new user account
    /login: POST - login to an existing account [aadhar card no + password]

Voting:
    /candidates: GET -  get the list of candidates
    /vote/:candidateId: POST - vote for a specific candidate

Vote Count:
    /vote/counts: GET - get the list of candidates sorted by their vote counts.

User Profile:
    /profile: GET - get the user's profile information.
    /profile/password PUT - change the user's password

Admin Candidate Management:
    /candidates: POST - create new candidate
    /candidates/:candidateId: PUT - update an existing candidate
    /candidates/:candidateId: DELETE - Delete a candidate from list
